## 1. VISÃO GERAL DA ARQUITETURA
O VideoMeet é uma plataforma e SDK de videoconferência e transmissão de vídeo WebRTC
Peer-to-Peer (P2P). A sinalização (SDP Offers/Answers e ICE Candidates) é gerenciada
em tempo real sem custos de infraestrutura e com latência ultrabaixa (<200ms).

A plataforma suporta dois modos operacionais principais:
1. TRANSMISSÃO PURA (Modo Stream / Pareamento de Câmera e Tela):
   - Transmissor (Sender): Capta a câmera ou tela local e transmite diretamente para o receptor.
   - Receptor (Viewer): Recebe o streaming P2P em tempo real com baixa latência.
   - Suporte a Modo Limpo (sem botões) e Controle Granular de Interface (escolher botões visíveis).
   - Ideal para: Câmeras de segurança, monitoramento, babá eletrônica, suporte remoto, live streams e IoT.

2. SALA DE REUNIÃO COMPLETA (Modo Meeting):
   - Grade adaptativa de participantes (desktop bento grid ou visualização WhatsApp mobile com PIP arrastável).
   - Chat em tempo real, reações de emoji flutuantes, levantar a mão, controle de áudio/vídeo, seleção de qualidade (144p até 4K) e compartilhamento de tela com ícone MonitorUp.

## 2. MODOS DE INTEGRAÇÃO VIA URL (IFRAME & POPUP)

A integração é feita via URL embedding em um <iframe> ou SDK JavaScript.

### 2.1. Parâmetros de Query String Suportados

| Parâmetro | Valores Possíveis | Padrão | Descrição |
|---|---|---|---|
| `mode` | `stream` \| `meeting` | `meeting` | Define se a sessão é transmissão P2P (`stream`) ou reunião (`meeting`). |
| `role` | `sender` \| `viewer` | `sender` | Em `mode=stream`: `sender` para transmitir câmera; `viewer` para assistir. |
| `room` | string (ex: `cam-101`, `abc-defg-hij`) | aleatório | O código da sala ou identificador de pareamento. |
| `controls` | `none` \| `all` \| `clean` \| lista (ex: `audio,video`) | `all` | Controla os botões visíveis ou oculta todos (`controls=none`). |
| `buttons` | lista separada por vírgula (ex: `audio,video,quality,fullscreen`) | `all` | Escolhe exatamente quais botões exibir na barra de ferramentas. |
| `clean` | `true` \| `false` | `false` | Se `true`, ativa o MODO LIMPO: apenas o vídeo puro sem nenhum botão ou cabeçalho. |
| `header` | `true` \| `false` | `true` | Exibe ou oculta o cabeçalho superior (código da sala, link, docs). |
| `toolbar` | `true` \| `false` | `true` | Exibe ou oculta a barra inferior de controles. |
| `name` | string (ex: `Carlos`, `Camera Sala`) | `Convidado` | Nome exibido no tile de vídeo e chat. |
| `embed` | `true` \| `false` | `false` | Remove margens e otimiza o layout para exibição embutida/iframe. |
| `audio` | `true` \| `false` | `true` | Estado inicial do microfone (`false` = mudo). |
| `video` | `true` \| `false` | `true` | Estado inicial da câmera (`false` = câmera desligada). |
| `quality` | `144p` \| `240p` \| `360p` \| `480p` \| `720p` \| `1080p` \| `4k` | `720p` | Resolução e taxa de quadros padrão do transmissor. |

### 2.2. Botões Disponíveis para Seleção no Parâmetro `buttons`:
- `audio`: Botão de mutar/desmutar microfone (ou som no viewer).
- `video`: Botão de ligar/desligar câmera.
- `switchcamera`: Botão de alternar câmera frontal/traseira (se houver múltiplas).
- `screenshare`: Botão de compartilhar tela.
- `quality`: Seletor de qualidade (144p até 4K).
- `fullscreen`: Botão de alternar tela cheia.
- `pip`: Botão de Picture-in-Picture.
- `leave`: Botão vermelho de encerrar ou sair da transmissão.
- `status`: Indicador de status/qualidade WebRTC P2P.
- `copycode`: Botão de copiar código no cabeçalho.
- `copylink`: Botão de copiar link do receptor.
- `docs`: Botão de abrir modal de documentação.

## 3. EXEMPLOS PRÁTICOS DE URLS

### A) Modo Limpo - Transmissão 100% Pura sem Botões (Clean Stream):
```text
https://SEU_DOMINIO/?mode=stream&role=viewer&room=sala-01&clean=true&embed=true
```

### B) Transmissão de Câmera com Apenas Botão de Áudio e Vídeo:
```text
https://SEU_DOMINIO/?mode=stream&role=sender&room=sala-01&buttons=audio,video&header=false&embed=true
```

### C) Receptor de Câmera com Apenas Botão de Som e Tela Cheia:
```text
https://SEU_DOMINIO/?mode=stream&role=viewer&room=sala-01&buttons=audio,fullscreen&header=false&embed=true
```

### D) Reunião Completa:
```text
https://SEU_DOMINIO/?room=reuniao-equipe&name=João&embed=true
```

## 4. EXEMPLOS DE CÓDIGO DE INTEGRAÇÃO

### 4.1. Código HTML Básico (Iframe Simples)
```html
<!-- Exemplo 1: Receptor de Transmissão Modo Limpo (Sem Botões) -->
<iframe
  src="https://SEU_DOMINIO/?mode=stream&role=viewer&room=camera-sala-01&clean=true&embed=true"
  width="100%"
  height="480"
  style="border: 0; border-radius: 12px; background: #000;"
  allow="camera; microphone; display-capture; autoplay; clipboard-write; fullscreen"
  allowfullscreen
></iframe>

<!-- Exemplo 2: Transmissor de Câmera com Botões Selecionados -->
<iframe
  src="https://SEU_DOMINIO/?mode=stream&role=sender&room=camera-sala-01&buttons=audio,video,quality&embed=true"
  width="100%"
  height="480"
  style="border: 0; border-radius: 12px; background: #000;"
  allow="camera; microphone; display-capture; autoplay"
  allowfullscreen
></iframe>
```

### 4.2. Componente React / Next.js com Opção de Controles
```tsx
import React from 'react';

interface StreamViewerProps {
  roomCode: string;
  cleanMode?: boolean;
  buttons?: string[];
  baseUrl?: string;
}

export function StreamViewer({
  roomCode,
  cleanMode = false,
  buttons,
  baseUrl = typeof window !== 'undefined' ? window.location.origin : '',
}: StreamViewerProps) {
  const buttonsQuery = buttons ? `&buttons=${buttons.join(',')}` : '';
  const cleanQuery = cleanMode ? '&clean=true' : '';
  const streamUrl = `${baseUrl}/?mode=stream&role=viewer&room=${encodeURIComponent(roomCode)}&embed=true${cleanQuery}${buttonsQuery}`;

  return (
    <div className="w-full aspect-video rounded-xl overflow-hidden shadow-2xl bg-black border border-neutral-800">
      <iframe
        src={streamUrl}
        title={`Transmissão ${roomCode}`}
        className="w-full h-full border-0"
        allow="camera; microphone; display-capture; autoplay; fullscreen"
        allowFullScreen
      />
    </div>
  );
}
```

### 4.3. Utilizando o SDK JavaScript (`videomeet-sdk.js`)

```html
<script src="https://SEU_DOMINIO/videomeet-sdk.js"></script>

<div id="video-container" style="width: 100%; height: 500px;"></div>

<script>
  // Exemplo A: Criar Transmissor em Modo Limpo (Apenas a transmissão, sem botões)
  const transmitter = VideoMeet.createSender({
    container: '#video-container',
    roomCode: 'minha-camera-01',
    clean: true
  });

  // Exemplo B: Criar Receptor com Botões Específicos
  const viewer = VideoMeet.createViewer({
    container: '#video-container',
    roomCode: 'minha-camera-01',
    buttons: ['audio', 'fullscreen', 'pip'],
    header: false
  });
</script>
```
